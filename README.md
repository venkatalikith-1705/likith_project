# Web Development Exercises

This workspace contains practical exercises for HTML, CSS, and JavaScript.

## Folders

- [HTML exercises](html/index.html): HTML pages, forms, tables, media, semantic elements, and Bootstrap examples.
- [CSS exercises](css/index.html): 270 numbered CSS exercises covering selectors, layout, responsive design, SaaS UI, analytics, AI/ML interfaces, and animations.
- [JavaScript exercises](javascript/index.html): JavaScript fundamentals, DOM, events, forms, browser APIs, storage, MySQL, Node.js, and Supabase examples.

## Opening the exercises

Open [index.html](index.html) in a browser, then select a topic. The HTML, CSS, and JavaScript indexes also link directly to their numbered exercises.

Some JavaScript browser examples require an HTML element with the id or class referenced by the script. API, Node.js, MySQL, and Supabase examples may require a local server, database, package installation, or service credentials.
